REEL 01 / FEATURED PROJECT · BETA

Universal Game
Localization

An OpenCode skill for translating supported PC game text. Python scripts do the file work locally, so AI can focus on translation.

View on GitHub ↗Release v1.4.0 ↗
01 / EXTRACTFind the translatable text

Collect supported game strings in batches.

02 / TRANSLATETranslate with your AI

Use your agent or hand batches off to a chat AI.

03 / CHECKValidate before patching

Check placeholders and Arabic text direction before building translated copies.

Still in testing. The core scripts detect some binary formats, including .pak and .locres, but don't unpack them. In-game rendering depends on the game.
